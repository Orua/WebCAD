# api.modeling.methods.output-quality-and-process

# 输出精度与制造条件

参考text-to-cad的supported-exports、migrations及DFM资料，输出格式先由用途决定：精确交换用已有BRep导出能力；STL用于网格交付；需要继续编辑时另考虑工程文件。文件后缀不赋予几何新的精确度。

显示精度、导出离散精度和建模几何精度是不同控制。text-to-cad某些网格误差参数使用部件包围对角线的相对比例；不能把这个数值移植成WebCAD的mm阈值。WebCAD的setRenderQuality是显示重网格化，不能由它推断STL导出公差或STEP精度；具体输出参数按当前files.export和相关契约。

检查网格交付时，把用户要求的精度与实际格式/分辨率分别记录。不知道导出离散规则时标未验证；不能通过把显示调成ultra就宣布加工公差合格。外观颜色/金属材质也不能证明真实合金、强度、板厚或制造工艺。

制造风险应先选工艺：冲压/钣金关注弯曲、避空与展开，CNC关注刀具可达、内角与深腔，模具关注脱模方向、倒扣和相应壁厚条件。只有现有工具能测、且有当前工厂/供应商规则时，才给带适用条件的数值判定。没有测量用review，没有适用规则或证据用unverified，不把通用参考升级为批准。

正常例：用户要STL用于展示，检查实际字节与网格形状，并说明未给加工公差。边界例：用户要精确STEP但手头只有三角网格，说明不能从网格自动恢复原解析曲面，不以改扩展名交付。
