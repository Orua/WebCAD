# 从需求得到可建模的问题

先用一句话回答：这是单件连续材料、可分离零件组合，还是只要曲面/展示网格？“钉”“圈”“底片”只是名称，不能确定截面、连接方式或尺寸。输出范围也要区分可编辑工程、精确STEP与展示网格。

从图纸读单位、版本、各视图和剖面，再把标注落到坐标。显式尺寸优先于照片比例；同一部位标注冲突应停止推断。照片可给外观比例，不能证明孔径/壁厚/配合。4X孔、盲孔底、沉孔、螺纹和背面结构单独列入验收项。能由约束确定的量直接计算，例如对称孔中心x=±孔距/2；不能由外宽减出未知内宽。

选择功能基准：板件以安装平面和孔距中线，轴件以轴线和端面，弯线件以路径起点和截面法向。写明坐标系、厚度方向、局部原点和部件间关系。WebCAD的box从角点到宽深高，cylinder以Z为轴、底面Z=0；模板常以中心布置，必须读卡确认，不共享想当然的原点。

一个有用的建模输入只保留：已确认尺寸与来源、需要的结构、必须保持的不变量、未知项、检查方式。简单零件不强制填大表。缺失会改变几何的厚度/孔位/截面/加工深度应补充；显示颜色等非关键选择可按用户已授权默认，不能从测试例子借尺寸。

已有模型先判断是否有可编辑特征；本项目新工程重开可能只保留最终形体，不能默认源配方还在。用当前getState/getHistory核实后选择feature.edit或新增明确加工，禁止以重建猜测替换原模型。
