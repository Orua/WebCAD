# api.modeling.methods.profiles-and-drawings

# 从二维轮廓到三维与工程图

参考dxf、engineering-drawing及金大福投影方法。先分清：二维切割轮廓、三维建模截面、三视图、剖切、带标注工程图、弯曲展开。它们目的不同，不能以一张投影替代全部。

建模轮廓先确认单位、平面、比例、闭合与内孔。保留真实直线/圆弧，不为方便拟合成大量短线。剪裁/层筛选后检查断点、自交、重复和零长实体；可用readVector获取支持来源，再sketchProfile/inspectProfile。profileRepair只在来源允许的最大端点移动内修指定问题，不能用扩大容差合并真实开口。偏移/带状轮廓用profileOffset，不能手工平移每个点来冒充等距偏移。

切割层必须按实际用途闭合；折弯线、刻线等允许开放的线不能被误补成材料。文字加工要审核字形轮廓和内孔，不依赖CAM再次挑字体。缩放前确认原单位，照片比例与实际矢量单位不是同一证据。

若已有可靠3D几何，二维信息优先从该几何推导，避免手工重画公式漂移。WebCAD真实工程图入口是createDrawing({context,bodyIds,projection,sections,hiddenLines})与exportDrawing；受当前卡中的实体/面数/截面数、权限和revision限制。图纸来源应与被交付模型一致，改形后旧drawingId需要更新。PDF、JPG、DXF、SVG按实际支持导出；不声称DWG可用。

三视图是可见/隐藏线投影，剖切是切面，不能互换。投影器的局部XY输出不能再错误取YZ/XZ，否则侧视会塌成线。正/第三角法、看向、up向及排版一致；对称轮廓也要核对左右/上下，不能靠包围盒通过。保留内部真实可见线，不能为了补外轮廓清掉全部内部结构。发现漏线先区分显示/投影问题，不能直接改三维模型。

带标注图应让尺寸落在真实几何上：孔中心与直径、通孔/深度、沉孔/沉头、剖面、投影法和单位明确。缺公差来源就只报名义值，不凭常用ISO字样生成制造批准。读回实际PDF/图像检查遮挡与标注重叠；漂亮截图不是工程图验收。

弯件的正投影不是展开料。没有经过验证的展开、折弯表/K因子和当前工具支持时，明确不能输出生产平面坯料；不把直观压平当作等价几何。
