# api.modeling.methods.verification

# 检查的是设计要求，不是成功字样

建立几个可判定的不变量：外形尺寸、截面、孔径/孔位/孔数、实体数、连接或间隙、局部深度/R、未指定结构。测量选择应对应标注：包围盒只证明外包络，不能证明孔径、壁厚或局部R；总体积正确也可能是错位去料抵消。

|要求|最小有效证据|不能替代它的信号|
|---|---|---|
|长宽高|measure的exact-brep bounds|画面看着差不多|
|孔径/孔距/孔数|当前圆边/孔壁的半径、中心、层位与数量；必要时材料点|单一体积差|
|通孔与盲孔底|目标方向贯穿证据/孔底Z、截面或材料检查|开孔工具返回committed|
|连续实体/分体件|solidCount及目标连接证据|bodyCount一个或包围盒相交|
|固定R或倒角C|当前目标边/面几何及对应参数；不支持独立检查时标人工复核|体积减少或视觉平滑|
|修改保留结构|前后关键尺寸/孔位/数量对比|新结果有效|
|精确导出|生成资源、读取真实STEP字节；需要时导回重测|文件名.step或mesh外观|

measure未暴露通用拓扑有效性报告时，不能声称已运行BRepCheck或自交全检。inspectDesign仅证明列出的来源/断言；未标注来源或assumption不能作为工厂批准。小数误差阈值是当前测试约定，制造公差须用户/工厂另行提供。

几何提交、匹配revision的渲染、资源生成、宿主写盘、生产部署分别报告。画面检查用于发现方向、遮挡、错位；不能覆盖精确检查。只做用户要求的导出/保存，不用额外文件制造完成感。模型请求/Token/端到端耗时无证据即null；工具内核毫秒不算Agent总耗时。
