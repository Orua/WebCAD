# api.modeling.methods.external-handoff

# 模型、制造资料与外部执行的交接

参考Gcode、Bambu、SendCutSend、机器人消费端验证与模型存储边界。模型合格、切片完成、打印发送、机器开始、供应商可接单是不同结果；几何成功不授予后续动作权限。

WebCAD交接先确认所需格式、实际模型revision、单位/原点、实体/零件结构、已测项及未测项。需文件时通过真实资源API导出并由宿主读字节/落盘；自包含性不能依靠本机热缓存或临时URL。不要把渲染截图、未取字节资源或过期下载链接当长期模型交付。

切片需要真实打印机/喷嘴/材料/层高与完整有效预设；不能猜温度、床尺寸或套一个同名预设。WebCAD当前没有切片或打印机控制工具；用户明确要求后才交给实际可用的宿主/外部工具流程，不能构造不存在的print/run接口。未配置就说明缺口，不自动安装或联系打印机。

供应商文件检查使用实际上传候选文件与当前材料/规格/工艺/服务规则；精确SKU/规格身份是关联门槛，近似名字不足。来源字段缺失、N/A或矛盾不变成0或pass。局部弯线、切口、支撑问题保留独立原因，不以一句“法兰短”掩盖所有问题。用户未要求上传/下单时只交付资料。

当模型导向仿真/规划等其他消费者，结构校验与消费者实际加载/行为测试分开。已有权威模型应派生输出，不重新手写另一套空间关系造成漂移。WebCAD当前不能验证机器人关节、IK或Gazebo插件；可迁移的是坐标/资产身份/证据边界，不是这些执行能力。

检查失败留存仍可用的模型和具体缺失资料。可选环境未安装属于未做该项，不自动把几何判失败；用户明确要求必须的消费端验证缺失，则任务该部分未完成。不要用“打开应用”冒充“打印/制造已经开始”。
