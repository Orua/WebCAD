# api.interaction

新插入的独立对象、导入和复制/阵列提交后清除选择（含通过预览应用及批量创建）；已有特征的参数编辑保留选择。body.appearance/document.appearance成功后清除实体与面边选择。setDisplayPreferences渲染字段、setRenderQuality和setView.display成功应用后同样取消选中，直接查看最终渲染。精度、主题、吸附设置不触发此规则。getState().selection读回空bodyIds/topology；需要后续加工时显式setView.selectedIds。鼠标与数值入口操作同一份工程。启动默认编辑页签、查看模式和透视投影；同源宿主控制见 api.host-control，锁定期间仅鼠标旋转/缩放/平移，page API 可继续建模；选择按钮或 V 进入实体选择，查看按钮或 Esc 返回查看。编辑页移动/旋转默认启用实体手柄，API 用 setView({context,gizmo:"translate"|"rotate",selectedIds?})；省略 selectionMode 自动转为 body，显式指定 face/edge 与该 gizmo 冲突返回 SELECTION_CONFLICT，host 未被调用。可以先启用模式再选实体；getState().view.transform 返回 {mode,bodyIds,attached,canDrag,blocker}。blocker 为 MODE_OFF、NO_SELECTION、MULTIPLE_SELECTION、HIDDEN_SELECTION、STALE_SELECTION、BUSY 或 null；attached/canDrag 表明当前单个可见对象是否已挂接、是否可拖。启用/取消手柄或更换选择不增加工程 revision，鼠标拖动松手通过 transform 提交一个历史步骤。精确数值变换先读 getTool({id:"transform"})；移动可用 params:{x:10,y:0,z:0}。绕指定中心旋转用 params:{mode:"rotate",pivot:[0,0,0],axisVector:[0,0,1],angleDeg:90}，并显式传 placement:{version:1,frame:{kind:"world"},sourceAnchor:{kind:"model-origin"}}；refs 必须是一个当前对象 ID。多个对象分别以 run 的 transform 步骤处理，atomic=false，遇失败前面的成功步骤保留。读回新 body/feature/revision 和 display.rendered。
绘制轮廓默认按图元点击，不要求用户配置全部选项；API 使用现有严格 sketchProfile 契约，显式传 entities 和 chains/loops/regions，output 为 wire 或 face，工作平面用 placement。先读 getTool({id:"sketchProfile"})；minimalExample 是完整可执行参数示例。线、圆、三点圆弧、矩形、折线等图元均保存为解析来源；参数矩形、圆角矩形、长圆的外环可直接引用其原始图元 ID 一次（entityId 为该 id，reversed 为 false），内部会自动展开有序边；不自动生成 loops/regions，也不要求猜派生边 ID。sketchProfile.normalExample 提供完整40×30矩形闭面；详见 recipes.rectangle-profile。二维 heightMm 不表示拉伸厚度，profileExtrude.distanceMm 必须来自用户要求。人工参数和高级编辑按当前任务显示；菜单页签、分组和展开策略保持用户原设计。inspectProfile({context,bodyId}) 只读诊断。prepareProfileEdit 为高级修剪/延伸/圆角提供明确 entityId/targetId 与交点候选，selectionRequired=true 时必须选择候选；不猜测交点。轮廓成体另用 profileExtrude，保持轮廓来源可编辑。
