# 用形状和控制尺寸选择构造路线

先问“哪个表达能直接控制关键尺寸”，不要从熟悉的工具反推形状。

|几何证据|优先表达|为何选择|转向条件|
|---|---|---|---|
|固定截面沿直线延伸|简单体、闭合轮廓拉伸|宽/厚/轮廓直接受控|截面沿长向变化则看放样|
|绕一条轴旋转不变|圆柱、圆筒模板或截面旋转|直径、轴向台阶和内腔容易核对|偏心凸台/横孔为后续加工，不能塞入旋转截面|
|同一截面沿空间路径|扫掠|保留路径与截面含义|截面尺寸在站位变化则看放样|
|多个不同截面连接|放样/已支持的引导放样|每个控制截面可独立表达|无源截面/轨迹时不能臆造自由曲面|
|规则重复结构且模板完全同构|具体template卡|减少确定性构造步骤|孔数、截面、沉头、装配结构不同则退回显式构造|
|已有精确体局部去料或加料|孔、槽、布尔/面加工|保留原件未指定结构|目标是mesh则不能套BRep路线|

同样叫D扣：圆线截面与扁带截面是不同问题；一个通用D形模板不能替代源件。圆片可用cylinder；带中心通孔的垫圈可用tube；偏心孔圆片仍需圆片加孔。铆钉若有钉头/台阶/盲孔，单个cylinder只代表其中一段。

决定轮廓画法时优先保留真实直线、圆弧和孔环。由采样拟合代替已知圆弧会丢失源几何；只有用户允许且误差标准明确时才谈近似。圆角可晚做以减少拓扑干扰，也可在二维轮廓里直接构造同样外形；后者必须证明截面、半径和连接关系等价，不能当作通用替代。

模板路线与显式路线均可正确。记录一个选择理由和转向条件即可，不强制所有零件都经过长方体→布尔→圆角，也不要求AI重新推导程序能确定的坐标。
