# api.modeling.methods.representations-units-and-mass

# 区分几何、显示、基准与物理量

参考CAD、URDF、SRDF、SDF的空间语义和假设账本，将通用方法转为WebCAD指导；不因此宣称支持机器人XML、IK、动力学、碰撞矩阵或动画插件。

同一部件可能有精确BRep、显示网格、导出网格、简化检测包络和工程元数据。用途和来源要标明；不能以简化包络证明真实孔槽，以显示材质证明合金，以相机旋转纠正实体坐标。若简化表示用于某项检测，说明其误差和未涵盖结构。

每个位置/方向说明在哪个坐标系。锚点冻结与当前工作基准不是同一东西；保存后重开也不能假设历史存在。局部原点、实际材料重心、包围盒中心和装配接口可能不同。变换顺序会改变结果，镜像会改变左右/轴向，不能只用一个视角看起来正确来验收。

WebCAD长度mm、角度按当前卡（通常degrees）；机器人参考中的m/rad不能直接搬过来。密度g/cm³与体积mm³换算：质量g=体积mm³×密度g/cm³÷1000。用getMaterials读取明确材料设置，以measureMass及其实际测量体积核对。均匀密度、未建倒角/孔或占位简化都会影响估重，必须注明。外观电镀与基体密度分开。

派生数值程序计算：直径转半径、坐标变换、阵列坐标、单位转换、体积与质量。用户只给总质量时不能由几何猜材料密度作为事实。质心/惯量若没有当前可核验工具或源数据就报缺口，不从渲染图自由手写精确矩阵，也不把惯量公式附在本库就说WebCAD已经支持。

身份和关联从当前实际对象清单取，不从相似名称记忆补齐。对象/源文件/工件版本变化后，相关位置、测量、配合与输出都需确认是否仍有效；画面能显示只证明一部分。复杂任务保留紧凑记录：来源、单位/标架、部件角色、控制量、假设、不变量和未测项，不强制简单件填机器人式大表。
