# api.modeling.methods.visual-review

# 用合适视图检查形状

参考text-to-cad的snapshot-review，迁移的是选择视图的判断方法；不迁移cadgen截图CLI、固定分辨率或其Viewer。WebCAD使用当前setView和capture。普通改动按本项目规则做一轮受影响检查，只有具体发现才增加视图，不强制四视图或截图循环。

检查板上孔阵列选沿板法向的正交视图，检查背面柱脚选能看见背面的视图，内部盲孔或壁厚可用当前setView.section能力查看剖切。透视投影可辅助理解空间关系，不用于直接量孔距。装配件隐藏或透明操作只改变显示时，也要记录实际被检查的部件和姿态。

capture需新鲜context；检查display中的revision与近似/细化状态。视图中看不到孔，先判断遮挡、相机和当前显示状态，不立即重新加工或改尺寸。圆柱周期缝、剖切显示边和真实裂缝不同：结合queryGeometry/measure的精确来源判定。setRenderQuality只改变显示网格，不修复BRep。

截图是辅助证据：能看见错位、反向、遮挡或轮廓异常，不能证明局部R、孔深、最小壁厚或全表面无自交。精确几何检查已通过但图像尚未查看时分别记录；不写视觉验收通过。截图生成、宿主保存和模型收到图像也是不同阶段。

正常例：两孔板顶视图辅助检查对称/位置，再用精确圆边中心确认孔距。边界例：底面朝向视图遮住盲孔入口，换至目标面或剖切，不重复钻孔。纯导出且几何未变不为凑检查另外建模。
