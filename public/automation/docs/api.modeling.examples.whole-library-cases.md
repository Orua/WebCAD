# 整库方法迁移后的例题与反例

全部为方法测试条件，不是工厂默认尺寸。

1. **源图D形方线件**：先定位正确图框/修订，交叉核对正视轮廓与侧剖面；只要已知5×5截面不代表四角R已知。保存源曲线、真实开口和横杆，选profileSweep或确实匹配模板。反例：换圆线模板后总包络相同，仍因截面错而失败。
2. **带刻线的板件**：闭合外轮廓和孔用于材料，开放中心/刻线不闭合成孔。readVector后分意图建sketchProfile，再选择profileExtrude/LOGO。反例：闭合所有线让切割检查通过，制造了原图没有的材料。
3. **工程图**：已有模型40×20×3两通孔，createDrawing取得与当前revision绑定的图，再exportDrawing；尺寸落在真实孔中心与边界，读回图纸。反例：用剖面圆冒充右视，宽厚对应错，漂亮PDF仍不通过。
4. **型腔可加工性**：要求内平面R2，候选刀半径3，几何上该刀不能形成该内角；换更小刀仍需查深度/刀柄/装夹。不能据此要求所有底壁根部加R，也不能自动改用户R2。
5. **拔模检查**：先给拉模方向和适用阈值，再inspectDraft；球面切向小带、顶底面和真实平行直壁分别解释。反例：给装配整体做遮挡，将盖子误算成底座倒扣，不能判模具失败。
6. **壁厚与partial**：只测一个点/一条射线就只证明该处。若某事实族返回error或null，报告unverified；不是壁厚0，也不是无薄壁。装配间隙不能当壁厚。
7. **标准件**：用户指定轴承型号，先核对可追溯源模型的内外径/宽/版本，宿主下载验哈希后import并复测。反例：服务断网就宣称没有该型号，并塞一个近似圆筒当真实配合件。
8. **周向重复**：确认数量、中心轴、相位及全圆首尾语义，再circularPattern；独立螺钉不union。反例：分度点含0°和360°，多一个重复部件却只看截图放行。
9. **估重**：确认真实实体体积1000mm³和用户确认密度8g/cm³，计算8g，并用measureMass设置来源核对。反例：选择金色外观后猜金合金密度，属于错误材料依据。
10. **打印交接**：先确认模型单位与封闭网格和工艺，再交用户要求的STL；无切片工具时明确尚未切片。反例：将显示精度ultra当作切片/支撑验证通过。
11. **空间变换**：供应商网格为mm、当前接口位置是局部端面。导入显式单位并按端面/轴定位，不能用相机旋转掩盖错误原点。反例：为让模型看起来大小合适，缩放但不更新孔距/配合证据。
12. **版本关联**：板加厚后原顶面、孔入口、LOGO落点、工程图和文件输出可能过期。查询当前依赖并仅补受影响部分；旧图/旧资源仍能显示不证明对应新模型。
