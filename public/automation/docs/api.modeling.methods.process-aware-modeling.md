# api.modeling.methods.process-aware-modeling

# 按制造结构理解模型，按证据选择检查

参考DFM、DfAM与SendCutSend的测量/规则分离方法。这里迁移的是判断流程，不移植供应商阈值、Python测量引擎或外部下单权限。

先问零件是机加工、钣金/冲压、注塑/压铸还是打印；材料、工艺、基准、孔和配合需求不明时不强行给生产结论。相同几何可能用不同工艺制造，一种刀具不可达不等于所有工艺不可行。用户/实际工厂规则优先；规则必须带材料、版本、单位和适用条件。

CNC：区分型腔平面内角与底壁交界，平底刀能形成某些锐底角，不要一律要求根部R。刀径能进腔还需查刀柄/深度/装夹；深孔、螺纹啮合、钻尖余量和偏心加工分开理解。WebCAD可用queryGeometry、measure、inspectThickness、inspectFit等取得局部事实，但没有刀具/夹具包络和路径验证就不能声称可加工、节拍或报价准确。需要松公差/改R时先确认功能允许。

钣金/冲压：确认真实等厚、内R/外R、法兰、孔槽、避空和折弯方向。孔到弯线的中心距、边距、切线距不同。局部切口可能截断法兰有效支撑，不能用整件最远外包络判断每一段足够；同轴分段弯线、重线和跨弯切割分别记录。只有受支持且已验证的展开才是坯料，不从投影推展开尺寸。

模具：先确认拉模方向与分型假设，再用inspectDraft按用户阈值检查已支持事实。面法向角不是完整倒扣证据；还涉及遮挡和完整退出路径。顶/底面不应因与拔模方向垂直就当零拔模壁；曲面切向小带也不能直接当整片直壁。按独立物理零件判断，不让装配中的另一个盖子成为底座“倒扣”。均匀壁、肋/柱交汇、顶出/侧抽与冷却是不同检查项；当前没测就报未核。

打印：先确认实际导出网格的单位、封闭性、法向/体积与打印工艺；inspectPrintability只证明它的当前返回项，不能照搬外部脚本的壁厚/支撑完整能力。粉末自支撑工艺与需支撑工艺不同，封闭腔的排粉/排液仍需检查。方向改变会影响支撑与高度，但不能把改变用户功能姿态当几何修复。

测量失败/partial/null不是0，也不是“无发现”。采样最小壁厚不是全件极小值；装配间隙可能被射线误记成壁厚，应按实际体分别测。采样/离散不确定度跨过阈值时标unverified。支撑体积粗估是成本信号，不能当准确切片耗材。

输出采用四类：有适用规则且测量满足→pass；有测量违反该规则→fail；仅定性风险→review；缺测量/规则/环境→unverified。每一项列对象/位置、事实、规则及具体下一步；不由工具success或模型自报给整件生产批准。
