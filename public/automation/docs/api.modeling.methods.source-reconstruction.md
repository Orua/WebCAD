# api.modeling.methods.source-reconstruction

# 从图纸和实物复刻，避免“形似但结构错”

从text-to-cad的cad/brief与本机金大福重构技能迁移方法，不复制具体货号尺寸或旧cadgen命令。先绑定产品、零件角色、修订和所用图框；整图含旧版/相邻产品/模具排布时不能按最低Y或文件名自动选。必要时对已确认图框局部读图，不能在看不清的缩略图上判无信息。

将正视、侧视、剖面和照片对应到同一部件与高度；照片可能倒置。侧视的圆可能是杆端面而非孔，正视带宽不能证明方截面。圆线证据要同时解释成对内外曲线、侧/剖面及明确线径说明。若不同视图的数据不一致，保留冲突，不自动平均成一个方便的直径。

源实体能提供解析曲线时保留LINE/ARC/闭合环及其来源。成对且同心的内外弧，才可用半径均值推导中心线、半径差推导径向厚度；非同心不套公式。LWPOLYLINE的bulge代表圆弧，不当折线；解析映射还须核对OCS/平面和闭合末段。WebCAD使用当前readVector/sketchProfile等公开能力；原始DWG读取若无受支持宿主通道，明确缺口，不虚构DWG页面工具。

区别图上显示值、DIMENSION实际measurement和引出点距离。内孔“高度”可能指两标注点，而不是曲线最大包络；记录标注落点和真实极值的差别。源实体与标注确实冲突时说明用途限制，不能移动轮廓凑四舍五入数字。

重构验收同义对比：源可见轮廓对实体真实投影，源剖面对实体剖切，标注对相应几何。双向比较内外轮廓，LINE/ARC都采样；仅采端点可能漏整条横杆，需在关键部位加材料/间隙检查。生成器计算的期望值不能独自证明生成器；保留能让错误旧模型失败的反例。

缺第三视图不一定阻塞：若源约束已唯一确定截面和路径，可以继续并验收；反过来不能因模板方便就忽略变截面、横杆或开口。内核失败属于实现问题，不能改写成源图证据不足。
