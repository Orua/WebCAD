# api.modeling.methods.parts-and-repetition

# 复用标准件与重复结构，而不丢失身份

参考step-parts、项目模型样例和预设继承脚本。先确认要的是用户源件、已命名标准件、完整匹配模板还是概念占位体。已知标准/品牌型号时，优先查用户提供或宿主能访问的可追溯模型；不能直接画一个近似盒子称真实标准件。

检索可用确切型号、标准号、常见别名和关键尺寸；多个相似候选要比较轴径、长度、接口、材料/版本，不只看名字。网络不可达只说明未查到服务，不等于零件不存在。外部搜索/下载由已授权宿主负责，本库没有向WebCAD注册step.parts工具，也不把其API描述当页面API。

使用已选模型时记录来源ID/版本、单位、原点、实际文件字节和可用哈希；下载后核对，导入后测实际尺寸与接口。不要覆盖原始供应商文件。只能用占位体时必须注明包络/简化/未验证接口，不能让占位体进入精确配合验收。

重复结构由确定性坐标生成：等距阵列用linearPattern，共轴周向用circularPattern，非规则可copy/transform。先说明重复的是独立实体、独立孔还是连续材料，合并与否按设计决定。count、间距/总角、首末项是否重复、局部轴/世界轴和相位均核对；全圆阵列不要首尾重复成count+1。

同一个模型的不同参数变体不是新的独立产品覆盖证据。重复件可以复用经核验静态构造，但实体ID、面边编号和当前状态不得复用。模板只有完整结构匹配才进入执行分支；原点/截面/孔数/内腔不一致时退回显式构造。

预设/参考的同名不代表同源，参数继承必须解析父链并核对实际有效值；缺父链、循环或同名多个来源要报冲突。这一思路用于识别当前WebCAD模板默认与显式用户参数的差异，不要求引入Orca预设系统。
