# 五金建模中的结构语义

来源为用户源图、PROJECT.md与当前模板卡，不是已批准工艺标准。先区分连续铸件、冲压弯件、独立铆柱和分体装配；图中接触不自动等于材料融合。板厚、线材截面、内开口、轴径、头部和盲孔分开确认。外观图不能确定背面柱脚、隐藏孔深或螺纹。

同名结构要比较：圆线圈不等于扁片圈，D形外轮廓不决定截面；实心底片不等于垫圈；铆钉/柱脚有头/颈/台阶时不能简化成圆柱；字母轮廓含孔环需保留；R为圆弧收边，C为平面倒角。需要相对运动的零件保留独立实体。

材料密度、最小壁厚、拔模、间隙、公差、收缩和表面处理均须明确来源与适用工艺。本库不编数值阈值，不把模板默认值或几何通过当作可制造/强度/开模批准。检查工具存在也不代表高级制造审查已完成。
