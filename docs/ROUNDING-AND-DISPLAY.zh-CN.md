# 圆边、选面过渡与全局显示设置

圆角、倒角、抽壳、普通布尔处理目标现有拓扑，不因工作基准变化重定位。吸附候选、工作锚点和预览是辅助显示，不是工程实体或可导出的几何。显示网格质量变化不改精确 B-Rep；检查操作回执的 `revisionAfter` 和显示版本，几何已提交但渲染告警时先刷新显示/查状态，不重复发送创建请求。

## 选边、选两个面倒 R / 斜角

在「修饰」中使用圆角或倒角：选中实体的一条或多条边，输入 R 半径或 C 距离；也可 Ctrl 选择同一实体上两个相邻面，直接处理它们的公共锐边。选择一个面时处理该面的边界，包括孔边。勾选整件时处理所有锐边，自动排除相切缝、周期接缝和退化边。凸角向实体内切除，凹角在凹处形成过渡；半径受局部壁厚、短边和相邻过渡限制，不能保证任意半径都成功。

API 对应 `fillet {radius,faceIds:[a,b],sharedFaces:true}` 或 `chamfer {distance,faceIds:[a,b],sharedFaces:true}`。`edgeIds` 为选边、`allEdges:true` 为整件。旧工程及省略 `sharedFaces` 的 API 保留所选面的全部边界语义。报告 `bodies[].blendReport` 返回处理边与排除的平滑边；失败给出边编号并保留模型，不自动减小参数或跳过失败锐边。圆角失败且目标边不超过 8 条时，工具会只读试算至多 11 个较小半径；找到有效单实体时在错误信息中给出一个实际试算成功的 R 值，供用户自行决定是否重新提交。该值不是最大可用半径，也不会被自动应用。

曲面法向优先沿原始 BRep 面内参数曲线计算，避免扫掠曲面上的三维投影失败被误报为「无法判定的边」。这修复了分类错误，并不消除原模型中真实的折缝或过渡面碰撞。

## 1. 整个实体自动圆边

选中一个实体 → 加工 → 曲面处理 → **整件圆边** → 填写 R 半径（mm）→ 预览 → 确认。

自动寻找实体的尖锐边，包括孔口、凹槽和文字边；已经相切的面缝、解析周期面的接缝不重复加工。所有目标边在一次内核运算中联动处理。半径不自动减小；任一部分失败或结果无效，整步不提交，原模型保留。

这不是“任意复杂模型都能一键成功”。窄字槽、短边、小面或接近相碰的圆角可能限制统一半径。TEST.stp 的全体文字边按 R0.1、R0.03、R0.01 均未通过，当前不能宣称这个样件整件已无利角；外围面组 R0.1 已成功。

## 2. 两个、三个或更多面之间过渡

切到 **面选择** → Ctrl 多选同一实体上两个、三个或更多相邻面 → 加工 → 曲面处理 → **平滑过渡** → 输入 R → 预览 → 确认。

只处理这些面互相之间的锐利接缝。不是在不接触的两个面之间填补空隙，也不是“三面全圆”或任意自由曲面补洞工具。

与未选面的结束边界仍可能锐利。属性会报告剩余锐边总数，AI 回执的 `boundarySharpEdges` 单列新增的未选面结束边界；局部过渡成功不能当作全件无锐边。

## 3. 更圆一点、退回一点

完成后选中结果，或点击左侧 **建模历史里的加工步骤**，在右侧修改 **圆边半径／过渡半径 → 应用参数**。

- 增大 R：圆角更宽、通常去除更多凸角材料。
- 减小 R：从加工前的源几何重建，退回较小的圆角。
- 撤销：恢复上一次已提交结果；反复修改 R 不会增加新的加工特征。
- 修改早期步骤后会重算后续步骤。若后续目标面改变或运算失败，整次修改不提交，保留原模型。面编号不是永久拓扑名称，上游形状大改后可能需要重新选面。

系统保存源引用、操作类型和参数，并复用内核缓存；不依赖对结果反复倒圆。导入 STEP 保留源几何，但不能恢复源 CAD 软件的原始特征历史。WebCAD 中新增加工步骤有可编辑参数；用户需要保存工程时，`.webcad` 可保留这些记录。

## 4. 金属为什么会一面黑、一面亮

亮金属主要反射周围环境。旧 HDR 的暗区和强亮区，加上偏低的粗糙度，会产生明显黑白分区。现在默认提供较均匀的 **工作室反射环境**，并按 WebCAD 的 Z 向上坐标转正环境。可切回原 HDR 作比较。

顶部 **全局设置** 提供：

- 默认设计颜色、默认材质、背景颜色。
- 主光方位、主光俯仰、主光与补光亮度、环境漫射亮度。
- 反射环境、环境旋转角、反射强度、金属柔和度和曝光。
- 标准工作室、柔和金属、明暗对比预设，以及恢复默认。

方位角围绕世界 Z 轴，俯仰角从 XY 平面起算。主灯是方向光，用方向角控制；反射环境旋转独立于主灯。金属柔和度越高，高光越散。

修改后点 **应用并记住**：配置保存在本机浏览器 Cookie，一年有效，后续页面启动自动载入。Cookie 被禁用时会提示只应用未保存；不同浏览器不共享。全局显示偏好不修改几何和工程撤销记录。

单个实体的颜色／材质仍在右侧属性。优先级：**实体材质覆盖 → 当前工程材质覆盖 → 全局默认材质**。工程覆盖在全局设置窗口下方，可切回“跟随全局默认”；工程覆盖和实体覆盖随工程保存、可撤销。全局默认颜色仅作用于没有单独指定颜色的实体。

## 5. AI 调用

显式数值输入按原值建模，包括小于 0.01 mm 的正尺寸；显示和鼠标步长不做隐式舍入。`dimensionPrecisionMm/anglePrecisionDeg` 是交互步长，与内核容差独立。人工输入、表达式、API、预览和提交遵守同一策略。工具卡 `numericInputPolicy` 及参数的单位/量纲注解说明策略；执行回执 `numericInput` 返回 `requestedParams/effectiveParams` 与 `quantizationWarnings`，默认精确策略不会量化。

按需读取 `getTool({id:'autoRound'})`、`getTool({id:'smoothTransition'})`、`readDocs({docId:'api.smooth-transition'})`、`readDocs({docId:'api.display-preferences'})`。

新增几何使用 `execute` 的 `feature.add`，严格携带当前工具版本和 schemaHash：

- 整件：`op:'autoRound', params:{radius:0.1}, refs:[bodyId]`。
- 面组：`op:'smoothTransition', params:{radius:0.1,faceIds:[当前面编号,...]}, refs:[bodyId]`。
- 重调：`action:'feature.edit', args:{featureId,opVersion,schemaHash,params:{radius:0.2}}`；使用原加工步骤 ID，而非新增一次圆角。

全局偏好使用 `setDisplayPreferences({context,values:{defaultFinish:'nickel',environmentMode:'studio',lightAzimuth:20,lightElevation:55}})`。可部分更新，完整字段和范围从工具文档读取。`getState().displayPreferences` 读回；`persisted` 表示 Cookie 是否写入成功。批次 `run` 也支持 `setDisplayPreferences`。

每次修改读取新 context，将其 `revision` 放入 `expectedRevision`，不要把只读 `revision` 字段直接传回请求。参数加工保留源引用，并从源几何重建。

## 校验范围

圆边结果检查 OCCT 实体有效性、封闭实体数量和非零体积，并在精确面与边的 20%、50%、80% 处抽样法向（1° 阈值）。此检测不等于每一个顶点无尖点的数学证明，也不代表制造后的触感验收。UI 与 API 使用相同几何结果和报告。

## 消息弹窗

### 选边与失败诊断（2026-09-28）

选边按屏幕距离优先，命中范围随缩放维持约 8 像素，并检查遮挡。边的点击点保留在该边上，不跨实体吸附到另一零件的顶点或中点。

内核先完成 Build 并检查 IsDone，再取实体和校验有效性。失败会报告目标/失败边、内核错误及相连边可测的小折角；不把未知失败原因一概说成半径太大。视觉接近相切的线弧接头可能有微小折角，但检测到折角不等于证明它是唯一失败原因；局部厚度、小面及曲面交汇也要核对。需要宽大连续过渡时，可能必须从来源轮廓或截面重建过渡面。工具不会擅自改变轮廓、自动缩小 R 或提交不完整曲面。

错误与警告使用独立居中弹窗；错误红色图标、警告琥珀色图标。关闭按钮、知道了或 Esc 可关闭，焦点返回原窗口；工具输入与当前几何保留。连续提示依次展示，重复提示合并计数。正常字段说明及几何结果报告仍保留在对应工具和属性中。
