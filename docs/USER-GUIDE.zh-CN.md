# WebCAD 使用手册

WebCAD 在浏览器本地完成几何计算，长度单位为毫米，角度单位为度。打开页面后等内核就绪，可从“路径”绘制轮廓、“创建”生成实体、“模型库”插入模板，或通过“文件”打开工程。顶部依次是编辑、路径、创建、模型库、加工、曲面、修饰、检查、视图、设置；左侧“对象 / 历史”切换并可搜索工程浏览内容，右侧根据当前状态显示工程摘要、对象参数或操作任务。快捷模型选择框也可按名称搜索。画布右上角的“俯 / 前 / 右”提供固定标准视角入口，完整方向仍在“视图”页签。保存 `.webcad` 保留可编辑历史，STEP 用于交换几何，STL 用于打印；STEP 导入不能恢复其他 CAD 软件的特征树。

## 参考锚点与坐标

画面只显示一个用于插入新实体的**参考锚点**，外观是小号呼吸球，可以从视口右下角隐藏或重新显示。固定的原始坐标系保持不动，界面不提供修改入口。锚点包含位置和插入方向；移动它不会移动已有实体。默认在锚点占位与新模型实体相交时，锚点沿 Z 向上避让到该列模型边缘；若新增实体不占据锚点位置，锚点保持不动。**来源基点**是待插入零件自身被对准锚点的点。基本体通常使用底面中心或包围盒中心；快捷模型和外部模型默认保留来源模型原点，也可明确选择包围盒中心。选择“保持来源坐标”时按原始坐标导入，不会自动居中。

特征创建时冻结使用的基准快照。以后修改尺寸使用该历史快照，当前工作基准不介入；若要让对象采用新基准，需要执行明确的重新定位或变换。旧工程和未带 `placement` 的旧 API 继续使用世界坐标语义；旧 `absolute` 仍指包围盒中心绝对位置。

## 编辑参考锚点

点击视口上方“参考锚点 → 编辑”，右侧打开编辑任务。X/Y/Z 输入框保留原始完整数值，输入或拖动仅更新草稿；点击“应用锚点”才产生一次可撤销的正式修改，点击取消或按 Esc 恢复原值。可分别重置位置、方向或两者；锁定可阻止 UI 和 API 意外修改。显示/隐藏只是当前浏览器的界面偏好，不改变模型或工程修订。拖动手柄可选单轴或平面约束；也可以不用拖动，直接输入数值。

“插入方向”可绕锚点自身轴旋转，或与当前选中平面精确对齐；“恢复默认方向”只重置方向。原有相对位移和三点定向代码仍保留，公开定位 API 的旧坐标含义也保持兼容；普通界面不再要求用户理解两套锚点。吸附不到时先选正确实体/边并放大，检查锁定和吸附开关；不能把网格点或圆心冒充面内合法点。

## 建模与加工

在“模型库 → 基本实体”中选择基本体，输入尺寸并确认，新实体按当前基准创建。板件例子：把基准放在 `[100,50,0]`，创建宽 40、深 30、高 6 的板，底面中心应在基准处，包围盒应是 `[80,35,0]` 至 `[120,65,6]`。快捷模型先在工具卡/对话框确认来源点和参数；不要仅凭显示图标猜来源点。外部 STEP/BREP 通过“文件 → 定位导入”选真实文件并设置来源基点；预览确认前可取消，不留下实体。

孔、槽、批量凹槽和凸台先选目标实体，再按对话框填写位置、轴向和尺寸。面孔要选当前精确面；若中心落在孔洞或面外、方向不兼容，操作应失败并保持原件。LOGO 先选目标面：平面支持加/减料，受支持的曲面仅保留现有等深凹刻限制。工作基准决定新刀具/图形方向，目标面法向仍必须相容。镜像、阵列、分割要明确选工作平面或轴；圆角、抽壳、普通布尔处理已有拓扑，不会随工作基准移动。

合并、相减、相交前按 Ctrl 选至少两个实体。任务面板明确列出“保留主体”和“加工工具”，可在已选对象中更换主体，并可勾选“保留工具原件”；应用与预览沿用锁定的角色。普通圆角/倒角需要选边、选面边界，或明确勾选整件全部边；没有选范围时不会默默加工全部边。

### 可编辑轮廓、偏移与加工

“路径 → 轮廓”可以输入解析直线、三点圆弧和圆。每段可修改坐标，圆按直径 Ø 输入；同一区域的外环、孔环必须首尾闭合。最多可保存 16 个分离区域，开放路径选择“线框”输出。提交时冻结当前参考锚点的位置与方向，之后移动锚点不会搬动旧轮廓。选中历史中的轮廓步骤，点击“编辑轮廓”可按原平面修改并重建后续零件。

任务里的平面绘图区可鼠标连续画线、两点画圆、三点画圆弧；它使用本任务局部 X/Y，与斜平面快照一致。可采用已选中的精确平面，正视绘制面，再恢复之前视角。区域浅色填充是候选预览，孔环留空，提交仍须通过精确检查。参数矩形、圆角矩形和长圆保存宽高与 R 定义；点击“转为独立直线 / 圆弧”后才能逐段任意修改，不再宣称保持原有矩形参数关系。直线的长度/角度按钮只设置本次终点，不建立永久约束。

旧“绘制草图”的预设形状与交互点线也共用当前参考锚点平面：进入手绘时视角自动对准该平面，点击坐标按该平面的局部 X/Y 记录；完成后按开始绘制时的锚点版本放置。绘制期间锚点若被其它入口改变，完成操作会拒绝，避免旧点落到新平面。

选择闭合轮廓后，用“路径 → 等距偏移”设置毫米距离、向内或向外、交线或圆角连接，以及线框、平面或等宽边框结果。偏移是精确曲线运算；距离过大导致崩塌或多解时会拒绝，不会把轮廓缩放充数。来源轮廓仍留在历史中。

选择已放置的平面轮廓后，用“创建 → 轮廓拉伸 / 加工”新建实体。加料、切除、相交需要另选明确的实体目标；“贯穿所选实体”只计算该目标的厚度，不加工旁边的零件。多区域轮廓可在一步中切出多个孔。面板的来源和目标在打开任务后锁定；要换目标，先点击“选择来源轮廓”或“更换加工目标”。普通查看其他实体不会偷偷改任务目标。一个成功的应用对应一个历史步骤和一次撤销，刀具不会留下成为普通实体。

### 键盘快捷键

在网页画布或普通按钮上，`Ctrl+A` 选择当前所有可见实体，`Ctrl+C` 复制选中实体到 WebCAD 内部剪贴板，`Ctrl+V` 粘贴为带 10 mm 递增偏移的可撤销副本；剪贴板仅对当前工程实例有效。`Ctrl+S` 保存，`Ctrl+O` 打开，`Ctrl+Z` 撤销，`Ctrl+Shift+Z` 或 `Ctrl+Y` 重做，`F` 适合窗口，`Delete` 删除所选。Mac 上可使用 Command 键代替 Ctrl。输入框内的全选、复制、粘贴保留文本编辑行为，活动任务中也不会把它们当作实体命令；保存活动草稿前须先应用或取消。

在轮廓编辑任务内点击“检查轮廓”，可先只读列出端点间隙、零长段、重复直线和非端点直线交叉；结果不会修改模型。保存后的解析轮廓还可通过页面 `inspectProfile` 查询。按 Ctrl 选中两个单一封闭实体，在“检查 → 干涉 / 间隙”输入本次接触容差：正体积重叠显示公共体积；无重叠时精确求最短距离及见证点，区分接触容差内与正间隙。结果绑定当前修订，模型变化后显示过期；没有装配阈值时只报告几何事实。

若开放线框末端接近起点，可先保存为 `wire`，再选择该解析轮廓使用“路径 → 轮廓修复”。面板列出具体端点间隙和允许的最大位移；例如 0.02 mm 的缝隙设为 0.03 mm 才能将指定端点对齐并生成派生平面面，设为 0.01 mm 会拒绝。原线框不改动，修复另记一步历史。首版只支持明确端点对齐，不能用它自动填补大缺口或擅自删除小孔。

## 定位已有对象

选择对象后用“变换”或“复制”。点到点只把明确的来源点平移到目标点，不暗中改变方向。指定中心旋转要求给出枢轴、轴和角度，枢轴保持不动。完整面贴合/轴对齐需要来源点、来源轴、来源面内方向以及目标点、目标轴、目标面内方向，并明确同向或反向、间隙和扭转角；缺项会报欠约束，不能任意猜姿态。可以从当前实体的精确顶点等参考建立具名对象锚点；锚点跟随可证明的刚体变换，无法证明映射的几何改形会将其标为过期，必须重新选参考。

使用设计树/历史编辑生成尺寸时，可先读取当前参数与定位快照。撤销、重做各对应一次已提交操作；拖动草稿和预览取消不增加历史。保存并重开 `.webcad` 后核对基准原点/方向、对象锚点、历史定位和实体测量。导入/保存前页面可能要求处理当前未保存修改；不要用刷新代替保存。

## AI 与错误恢复

AI 在已授权的同一浏览器标签页通过 `window.webcad.api.connect({queries:["工作基准"],includeContracts:true})` 读取实时上下文、版本和工具卡，随后按卡片执行。参见 [页面 API](PAGE-API.zh-CN.md) 和 [工具发现](AI-DISCOVERY.zh-CN.md)。不需要额外后台服务。拓扑 ID、referenceId、预览 ID 与版本只对当前工程实例和 revision 有效；收到 `STALE_REFERENCE`、版本冲突或预览代次错误时，重新查询、重新选择，不盲目重试。预览提交前先核对 `previewId` 和 `generation`。提交后若显示失败，要检查回执和工程状态，避免重复建模。

## 精确检查与加工扩展

轮廓编辑器支持明确选择线段或圆弧做修剪、延伸，以及两条相交直线的指定半径二维圆角。无交点、多候选或半径过大时会拒绝，不能把屏幕上的交叉当作同一平面中的真实交点。选择模型中的精确边后，可在轮廓任务中点击“投影已选精确边”；线、平行圆和圆弧以几何快照投到本次任务平面，不会随来源后续修改偷偷移动。非平行圆目前明确拒绝。

“检查 → 关系测量”可测有限实体间最短距离、两解析圆的圆心距和轴关系、世界点到有限面的距离、平行面的法向和有限最短距离。“检查 → 指定位置壁厚”需要实体上的真实表面点与指向材料内的方向，返回第一段连续材料厚度；也可在两个平行面之间指定位置。它不是整件最小厚度搜索，擦边或朝空气的射线会拒绝。检查记录依附工程修订；改模型后应重查。

轮廓拉伸的“到平面”要求固定世界平面的一个点、法向，以及沿拉伸方向加上的有符号余量。首版只支持与来源轮廓平面平行的目标平面；斜切终止面明确拒绝。目标是该无限平面，不声称停止在某张有限面的边界。目标在反方向时也拒绝。

“加工 → 孔向导”在同一个锁定实体上选择普通孔、圆柱沉孔或锥形沉头孔。输入小孔 Ø、入口点、切入方向和盲孔深度，或选择贯穿；沉孔还需大孔 Ø 和圆柱深度，沉头孔需大口 Ø 和**锥体包含角**。沉头深度由 `(D-d)/(2×tan(包含角/2))` 派生。盲孔到达第一段材料出口会被拒绝；贯穿会切通所选实体沿轴线上的全部材料，包括空腔后的壁。不会修改旁边其他实体，不生成真实螺纹几何。一次孔型操作只提交一个可撤销历史步骤。

“检查 → 拔模检查”选择拉出方向和本次阈值，读取解析平面的精确有符号倾角；封口面单列，非平面标为未支持。负倾角本身不是已证明倒扣。“修饰 → 拔模”首版只接受六平面、十二直边的单一棱柱；切换到面选择，用鼠标多选四个侧面，再点击“使用当前四个面作为侧面”；选择底面并点击“使用当前面作为固定底面”。面板会列出已确认范围，普通选择不会替换它。选择拉出方向和小于 45° 的正角，先预览再应用。成功后固定底面不动并生成精确实体；圆柱、圆角、样条和无法确认传播范围的拓扑会整步拒绝。检查和建模均不宣称压铸工艺合格。

壁厚检查可从方向下拉框选世界轴或所选面的向内法向；两面模式从面列表选择，不需要填写拓扑编号。草稿切换提示使用网页内的“保留草稿 / 放弃并继续”，取消提示不会丢失参数。模型修订变化后，关系、配合、壁厚及拔模结果显示过期。

视口工具提供“仅看选中”“其余透明”“恢复显示”；这些只用于临时查看，恢复时仍保留用户之前隐藏的零件。Alt+单击模型可列出沿该视线的实体/面/边候选，明确选一项；属性里的面/边范围显示计数，可逐项移除或清空。轮廓修剪、延伸与二维圆角先选稳定图元与交点，悬停或聚焦“应用到轮廓草稿”可看红色移除区间和绿色新增区间；局部撤销只改草稿。整圆修剪需线框输出，并选择两个不同交点与保留方向。


## 2026-09-26：模块路由、主题和交互

- 菜单按对象编辑、路径处理、实体创建、模型复用、加工、曲面、修饰、检查与显示划分；“设置”包含主题、显示、导入配置、拖动吸附、语言、命名参数及 AGENT 接口。分组名称只出现在 title，界面不绘制分组文本；按钮 title 为分组 > 功能。
- 默认蓝色主题；主题主要颜色和吸附阈值保存在当前浏览器，同源下次打开自动载入。命名参数是可被多个尺寸表达式引用的工程数值，例如壁厚=2，修改后引用尺寸一起重建。
- 空视口不显示快捷模型卡或插入按钮；底部状态栏隐藏，错误仍通过消息面板显示。参考锚点状态、编辑与显隐放在视口右下角，不显示投影状态标签。
- 两侧面板收起后各32 px，只有展开图标，没有标题、数量或竖排文本；展开后右上角减号收起。新建建模任务会展开属性面板。
- 视图中的透视+边线显示半透明实体、真实边线和曲面显示三角网格。网格线是渲染辅助，不是精确等参线或几何编辑。
- 实体平移和锚点拖动松手时，按精确 B-Rep 最近边界吸附；默认20丝=0.2 mm，可设置0–10 mm，0关闭。隐藏对象不参与，轴约束不被破坏，旋转不自动吸附。成功吸附后下一次拖动自由微调，再之后恢复吸附。数值输入不会自动改写成吸附值。
- AGENT 使用原有 window.webcad.api。已知操作 connect({toolIds:[...]}) 精确载入，未知操作 connect({queries:[...],limit:1,includeContracts:true}) 按需发现。knownHashes 只缓存完整工具契约，实体身份和修订必须重新读取。静态快速说明及离线知识库保持原地址，不新增后台。

## 从 DWG / DXF 直接取线并闭合成面

入口：**路径 → 导入与连接 → 矢量取线成面**。

1. 选择 DWG、ASCII DXF、受限 SVG 或解析轮廓 JSON；也可以在文本框粘贴 DXF/SVG/JSON。DWG 二进制请选择文件。
2. 核对源单位，DWG/DXF 默认每单位 1 mm；非毫米图请改比例。SVG 无物理尺寸时填写目标毫米宽度。
3. 滚轮以指针为中心缩放，拖动框选完整截面，单击增减线。标注、文字、块和样条暂不导入，并显示略过数量。
4. 点击“自动连接与检查”。工具自动排序、反向、配对唯一相邻端点，识别闭环和孔洞。默认只连接间隙不超过 0.000001 mm 的端点；可明确调整容差，结果会报告最大移动量。断口、分叉、重线、自交须先处理。
5. 检查尺寸后点击“生成面”。由精确内核校验，通过后创建可编辑 sketchProfile；再按需要扫掠、拉伸。源坐标默认保留，居中和上下翻转均需显式选择。

DWG/DXF 的 LINE、ARC、CIRCLE 和无宽度 LWPOLYLINE（含 bulge）保留解析曲线。SVG 沿用受限填充轮廓解析，曲线为约 0.005 mm 的离散近似；不应当作原始解析圆弧。单次成面最多 500 条边、50 个环、16 个面区域。尚不展开 INSERT 块、不读取非 XY 平面曲线、不自动补造缺失的长边。

AI 使用同一 `readVector` 和 `connectVector` 页面 API，详见 `api.vector-import`。读文件只在浏览器本机解析；DWG Worker 完成后释放，避免长期占用解析器内存。

## 路径菜单

顶部“路径”集中提供常用路径工具，已移除其它主菜单中的重复入口：

- 导入与绘制：矢量取线成面、解析轮廓（直线、圆弧、圆、矩形等）、导入路径、螺旋线。
- 编辑曲线：编辑路径、二维圆角、修剪、延伸、整圆裁剪。编辑路径内还可改端点、长度与角度、删除段、闭合轮廓和切换线框/面输出。
- 闭合与尺寸：端点间隙修复、尺寸约束、等距偏移。
- 提取路径：面边界、平面截面。
- 路径对象的移动、旋转、复制、镜像统一使用“编辑”菜单。

修剪/延伸/整圆裁剪通过解析轮廓编辑器选择图元及交点。二维圆角支持直接在主视图操作：切到选边，单击第一条直边，按 Ctrl 或 Shift 单击第二条相邻直边，点击“路径 → 二维圆角”，输入半径 R 后“应用圆角”。两边选择先后不限；多选了边可再次 Ctrl/Shift 点击该边取消。支持原始 sketchProfile 及其未缩放的移动/旋转副本，按精确几何回溯来源，不把屏幕边号当作图元顺序。自动修剪两条直线并插入相切圆弧，保持闭合；过大 R、非相邻边、曲线或不明确来源会报错。修改原始轮廓会一起重建依赖它的副本与后续特征。AI 用 prepareProfileEdit 的 bodyId、edgeIds、radiusMm、arcId 获取 profile/sourceFeatureId，再 feature.edit 提交。编辑路径内仍可使用草稿二维圆角。

菜单工具按常用和操作流程排列：路径以导入/绘制、编辑、闭合与尺寸、提取排序；创建以轮廓加工、扫掠、旋转、放样排序；加工先布尔后孔槽、车削；曲面先提取/生成，再修剪、偏移、缝合、增厚；修饰优先圆角、倒角与整件圆边。编辑先复制粘贴再变换，检查先测量再壁厚/配合，视图先视角与投影再显示，设置优先精度与吸附。

# 圆角操作（2026-09-30）

在“修饰”中选择“圆角”。先选中需要圆润的实体边，输入“圆润大小 · mm”，点击预览核对实际影响范围，再确认。新入口不要求选择算法或模式。确认提交当前预览，参数改变后须重新预览；历史参数中可修改大小并重新生成。

曲面生成的样条圆角面会核验实际圆截面和半径；闭合无分叉轮廓会检查生成面的接顺状态。原生拟合精度已收紧，大小保持输入值。
