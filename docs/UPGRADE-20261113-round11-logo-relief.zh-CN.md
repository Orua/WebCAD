# 升级说明 1.69.0 — LOGO 雕刻与平面浮雕（Round11）

## 行为变化
- 平面凹刻 LOGO 若刻穿薄壁、使字形内岛脱落（如 A/B/D 的孔芯掉出），不再提交多实体结果，而是拒绝并说明「刻深超过壁厚，字形内岛脱落」。曲面等深与跨面投影路径原先已有类似检查，保持不变。
- `readVector` / 本地 SVG 导入对接近整圆的圆弧按 three.js `aClockwise` 计算真实扫角，并核对离散偏差不超过声明的 0.005 mm 容差，不再把大弧收成四段菱形。
- 分层浮雕的凹刻层（`mode:'engrave'` 且只有 regions）不再被误判为尚未验收的「密集刻线」。仅显式 `strokes` 仍走 TBD 语义 `relief.compiled-contours-strokes-1.2` 并禁用。
- 平面光滑轮廓浮雕在轮廓内部对高度 0 施加默认 0.005 mm 最小肩部，避免顶面与主体面重合导致「未能保持一个有效封闭实体」。层高度 `heightMm` 仍是相对原主体面的绝对峰高，不会额外叠高。
- 面向用户的错误会保留内核给出的具体原因（中文或简洁英文），不再把 “region 0 crosses the selected face boundary or a hole” 收成笼统的构造失败。`OPERATION_TBD` 会带上真实能力标签（如「密集刻线」）。柱面图案角宽/半径限制按几何输入分类，不再建议去拆分工程或释放资源。
- 分层 `startHeightMm` 在没有足够下层承托时，会在布尔之前拒绝并说明缺少支撑。
- 浮雕工具卡标明层参数 `strokes` 为 TBD（来自 `tbd-capabilities.json`）：尚未完成验收，已禁用；请将刻线缓冲为 `regions`。
- 柱面 LOGO 过宽时不再只说「投影为空」，会写明可见半周宽度、当前不支持环绕展开，并给出建议比例。

## 兼容性
- 凹刻结果如果会增加实体数量，现在是失败而不是提交。需要打通孔且不掉岛的切割仍然可以（仍为单一实体）。
- 分层浮雕凹刻层可在本地按原轮廓语义执行；含 `strokes` 的层仍被拒绝。
- `RELIEF_LIMIT` 在角宽/半径等几何限制下的恢复分类改为 `source_parameters`；像素/文件/面数等容量限制仍为 `capacity`。

## 基线
- 基于 main 1.68.0（`5274801d`）。pageApiVersion 1.69.0。catalogHash 与 docsHash 以本分支最新生成清单为准。本说明不授权生产发布。
