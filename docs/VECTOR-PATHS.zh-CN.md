# 矢量路径导入与生成几何

矢量轮廓先保留源文件二维坐标和轮廓原点；新 placement 的 `sourceAnchor` 明确选择来源模型原点、包围盒中心或点，框架中的局部 X/Y/Z 再映射到世界。不要在导入和放置两处重复平移。旧 API 未给 placement 时保持既有世界坐标解释。轮廓与孔环的验证仍由原内核负责，工作基准不替代面内合法性检查。

入口：创建 → 轮廓成型 → 导入路径。无需先创建或选择实体。

1. 选择 SVG、DXF、DWG、矢量 PDF、PDF 兼容 AI 或现有 `.logo.json`；也可粘贴 SVG 文本或 SVG path 的 d 内容。
2. 文件导入沿用页码、框选范围与单位换算；点击提取轮廓，核对孔洞和毫米尺寸。
3. 选择生成面或实体；填写工作平面、位置 XYZ、比例、面内旋转角。实体需要非零厚度，负值向反方向拉伸。
4. 预览并应用。生成面以后，可在该历史步骤的参数中改为实体并设置厚度。

位置 XYZ 是导入轮廓外接矩形中心所在的世界坐标。XY 平面正方向为 +Z，XZ 为 -Y，YZ 为 +X。多块不相连图案保留为多个面/实体，内部孔洞保留。生成面没有体积，不要将它误当成实体。

剪贴板支持可读取的 SVG/XML 或路径文本；可在文本框按 Ctrl+V，剪贴板按钮读取失败时用文本框粘贴。Illustrator/Corel/CAD 原生复制可能提供私有数据或位图，不能保证直接粘贴；这种情况请另存 SVG、矢量 PDF 或 DXF。位图不自动描边，文字应先转曲。SVG 默认像素按 96 DPI 换算毫米，务必核对尺寸。

建模使用闭合轮廓；未支持的裁剪、描边、开放线网络、自交及损坏文件会提示失败。曲线沿用导入器的离散精度，不保证与原始贝塞尔/NURBS 参数曲线完全相同。局部转换仅使用本机服务。

MCP 新增操作 vectorProfile，无 refs：regions 与 LOGO 共用格式，output 为 face 或 solid；plane、x/y/z、scale、angle、height 控制放置与拉伸。可通过 get_operations 查看完整参数，旧服务缓存需正常重启后更新。

纯路径 d 文本按 1 坐标单位 = 1 mm、奇偶填充解析；完整 SVG 保留文件本身的单位。修改粘贴文本会作废之前提取的轮廓，须重新读取和提取。
