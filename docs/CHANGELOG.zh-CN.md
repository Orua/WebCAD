# WebCAD 更新日志

## 2026-10-09

本次记录当前工具开发分支相对上一提交 `93fc573` 的更新。

### 浮雕与精修

- 新增分层矢量浮雕，支持通过 `.relief.json` 导入各层高度、起始高度、方向、闭合轮廓和开放刻线；交叉刻线先进行二维并集。
- 提供显式轮廓清理精度 `contourSnapMm` 和线弧拟合容差 `curveToleranceMm`；保留原底面与图案孔洞，空白区域不额外添加底片。
- 新增浮雕精修面板，提供抬高、压低、平滑、定高、填洼、削峰、锐化、恢复与遮罩笔刷，支持硬度、双轴对称和高度吸取。
- 精修增量独立保存于 `params.sculpt`，保留源高度图和轮廓；支持平面及外凸圆柱面上的平顶/起伏、凸雕/凹雕。拖动增量刷新预览，应用后重建精确 BRep。
- 切层或关闭面板可保留本标签页草稿；正式保存工程前须先应用。来源变化会使草稿过期。
- 优化图案边界检查、等高网格和复杂图案容量，修正圆柱面浅刻与多层细节的构建路径。

### 圆润工具

- 新增显式平面选择范围，按所选真实平面的完整边界进行边缘圆润；UI 与 AI 共用 `faceIds` 契约。
- 平面范围与选边范围互斥，并拒绝混用端头参数；显式半径保持原值，自动建议半径参考相邻侧壁高度。
- 新增 GC15664 LL 真实轮廓回归用例，验证 219 条轮廓边的 R0.2 圆润，以及带孔平面的孔洞保留。

### AI 接口、进度与依赖

- 新增只读 `sampleReliefHeight` 和精修草稿 `prepareReliefSculpt` 接口，接入批次调用；草稿准备返回后续拓扑引用的提交阻塞信息。
- 后台任务 `getJob` 返回当前内核阶段、进度与运行时长。分层浮雕提供逐层、逐轮廓进度；三分钟无新进度或总计十分钟时终止。
- 同步公开工具卡、UI/API 映射、页面 API 文档及可下载知识包。
- 引入固定版本 `polygon-clipping@0.15.7`，补齐相关第三方许可证说明。

### 本次提交前验证

- 37 项浮雕/精修/圆润契约、圆润对话框和页面 API 测试通过。
- 24 项浮雕、精修和圆润内核测试通过。
- `npm run build` 通过，发布检查覆盖 75 个操作、28 个动作及 161 条 UI 路由；保留构建体积提示。
- 本次未重新进行浏览器现场验收或生产部署。上述测试不代表所有产品几何均已验收。

### 范围与限制

- 浮雕精修控制网格为 4–65，笔刷半径至少一个网格间距；不是任意 STEP 或一般自由曲面的雕刻器。
- 独立工作目录中的远程 Agent 接入尚未合并，不包含在本次工具分支提交中。
