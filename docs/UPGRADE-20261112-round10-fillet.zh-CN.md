# 升级说明 1.68.0 — R角 / 圆润剩余问题（Round10）

## 行为变化
- 主「圆润」只选实体或只给半径时，按整件锐边处理（默认 `allEdges:true`）。显式混用边/面/整件范围仍互斥。
- autoRound、smoothTransition 超限时与 fillet 一样报告「可用最大约 Rx」；`radiusFallback:'maxFeasible'` 会应用该已试算半径。
- 自动打磨默认可以只打所选边，不再因为扩网而直接失败。整件或网络上的混合凹凸按材料方向分组处理，不再整单拒绝。
- 折线圆管在折角椭圆上若原生过渡构不成，会按脊线把折角重建为圆环肘管（路径弯半径约为管半径加请求 R，并按段长裁剪），再圆端盖；仍构不成则诚实失败并保留原模型。其他曲面交线构不成时，会做可行半径/分组试算。不假成功。
- 相切/贴面并集若留下单侧面边，会尝试 shift/fuzzy 修复；整件圆角跳过无法取得两侧法向的边并给出警告，继续处理其余锐边。
- 不相交的并集若仍为多个实体，回执写明「未融合、仍为 N 个实体」。随后圆角提示「请先合并为单一实体」，不再报成顶点收口。
- 倒角后再整件圆角时，getState 会写回精确体积和面积，属性面板不再为空（几何本身原先就是成功的）。
- 已有较小圆角后再做更大整体圆角：若支撑面都是平面，先恢复原锐边再按新半径整件圆角，结果为均匀的新 R。恢复不适用时，仍完成剩余锐边；交汇处若留棱会在回执里说明。不提交未通过验收的结果。

## 兼容性
- `round` 省略范围现在等于整件圆润，不再返回「必须且只能选择一种参数格式」。需要选边或选面时请显式传 `edgeIds` / `faceIds`。
- autoRound / smoothTransition 新增可选字段 `radiusFallback`。
- 不相交并集的回执增加 `booleanReport.fused` / `solidCount` 和警告，仍可能提交为组合体。

## 基线

## 续修（同一 1.68.0 未发布分支）

- 整件更大 R 会升级已有较小平面支撑圆角；已全部圆好的更小 R 再请求更大整件 R 不再是 `NO_CHANGE`。更小或相等的后续半径仍是 `NO_CHANGE`。
- 折线圆截面扫掠的折角改走 `tube-spine-corner-rebuild`。A34 圆管 r=3 整件 R1 成功，0 条锐边。

- 凹形平面-平面已有圆角（例如 L 内凹边 R2→整件 R3）改为局部互补楔恢复后再倒新 R，体积与直接整件新 R 一致。箱体仍走半空间恢复。若结果里仍有未升级的较小半径，即使 0 条锐边也会在回执里说明；已光滑但无法安全恢复时是带残留半径说明的 `NO_CHANGE`。柱端圆环与带球面顶点的全圆凹体尚未能整体升级。
- 折线圆管短段/紧折角会使用仍大于管半径的最大可行弯半径，并允许肘管贴齐端盖；端盖可按可行值下调。臂长小于管半径的 90° 折角是几何极限（实心圆环弯头需要弯半径大于管半径），失败回执写出需要的弯半径与段长能放下的最大值。
