# 升级说明 1.68.0 — R角 / 圆润剩余问题（Round10）

## 行为变化
- 主「圆润」只选实体或只给半径时，按整件锐边处理（默认 `allEdges:true`）。显式混用边/面/整件范围仍互斥。
- autoRound、smoothTransition 超限时与 fillet 一样报告「可用最大约 Rx」；`radiusFallback:'maxFeasible'` 会应用该已试算半径。
- 自动打磨默认可以只打所选边，不再因为扩网而直接失败。整件或网络上的混合凹凸按材料方向分组处理，不再整单拒绝。
- 折线圆管、曲面交线等构不成时，会做可行半径试算；整组没有统一半径时报告分组试算结果。不假成功。
- 相切/贴面并集若留下单侧面边，会尝试 shift/fuzzy 修复；整件圆角跳过无法取得两侧法向的边并给出警告，继续处理其余锐边。
- 不相交的并集若仍为多个实体，回执写明「未融合、仍为 N 个实体」。随后圆角提示「请先合并为单一实体」，不再报成顶点收口。
- 倒角后再整件圆角时，getState 会写回精确体积和面积，属性面板不再为空（几何本身原先就是成功的）。
- 已有较小圆角后再做更大整体圆角：优先完成剩余锐边；与既有圆角交汇处若仍有棱，会在回执里说明，不再整单失败。仍不提交未通过验收的结果。

## 兼容性
- `round` 省略范围现在等于整件圆润，不再返回「必须且只能选择一种参数格式」。需要选边或选面时请显式传 `edgeIds` / `faceIds`。
- autoRound / smoothTransition 新增可选字段 `radiusFallback`。
- 不相交并集的回执增加 `booleanReport.fused` / `solidCount` 和警告，仍可能提交为组合体。
