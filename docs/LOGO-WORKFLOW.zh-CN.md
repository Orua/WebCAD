# 从工程图复用 LOGO

当前页面 LOGO 先选目标精确面，工作基准/显式 placement 决定新图形的方向与起点，目标面法向和修剪范围仍须相容。平面可按原有凹凸规则加工；曲面路径保留原有等深凹刻限制，不能把统一工作基准理解为任意曲面凸字支持。保持来源坐标的矢量轮廓不自动移到零点；旧调用未带 placement 时仍按世界坐标。选面、预览、提交应使用新鲜 revision，失败后重新查询面而非复用旧拓扑编号。

WebCAD 的“加工 → LOGO”是一个入口。浏览器直接读取 `.logo.json`、受限 SVG 或粘贴的 SVG / 闭合路径；选择一个精确 BRep 面后，平面可凹刻、凸字、拔模，受支持的曲面可做单面等深凹刻。轮廓须有实际来源和已核对的尺寸；不能凭客户名称猜字体，也不自动修复散面 IGS。

## 直接导入文件

1. 打开 LOGO，点击顶部“到模型上选面和放置点”，在模型目标面上单击所需位置。界面自动返回 LOGO 设置；确认过的轮廓及加工参数保留。也可先选面，再打开 LOGO。
2. 选择 `.logo.json` 或受限 `.svg`，或粘贴完整 SVG / 闭合 path `d`。无物理尺寸时必须填目标宽度（mm）。浏览器本地解析，不请求旧 `/api/logo-import`。
3. 检查安全轮廓预览、内孔、物理尺寸和来源，点击“确认轮廓和尺寸”。输入深度，核对曲面能力，再预览精确几何并应用。未选择单个目标面和放置点时，预览与确定不可点击。

本地 SVG 只接受单色不透明闭合填充、`svg/g/path/rect/circle/ellipse/polygon`、规定的路径命令和可逆二维变换。文字、位图、描边、外链、脚本、滤镜、蒙版、裁剪及不支持的样式会被拒绝，不能靠渲染成功冒充可加工轮廓。复杂格式应在原设计软件转曲，或使用另行部署且经验证的转换服务。旧本机转换服务属于历史路径，当前静态站点不提供。

源文件限 20 MiB，`.logo.json` 限 2 MiB；最多 150 个填充区域、每环 2000 点、总计 12000 点。换文件或目标宽度会作废旧轮廓确认与预览。自交、接触孔环或开放路径直接拒绝。SVG 曲线源尺度的离散误差约不超过 0.005 mm；等比缩放后误差随比例变化，界面会显示。

直接导入只需当前 WebCAD 静态页面；不要求 Node/Python 转换服务在生产运行。`scripts/serve.mjs` 可用于开发与本地预览，不能把它当作格式转换能力的证明。

## 本批图纸带来的规则

- GC15763：产品侧视图有 LANCEL 轮廓和“凹字”批注，不能只读取标题栏的客户名。
- GC16191：同一 DWG 上下两个产品视图中的 CHAVARRIA 字体不同；“双面凸字、凹位留细沙底”要求两面分别加工，凹底质感与凸字几何分开处理。不能仅凭同货号共用一份字形。
- GC16607：单侧面凹字 CHARLES & KEITH。此轮转换轮廓存在微小断口/重叠，未自动补线。
- GC16190：同时有凹字凹线条、凸边凸字；字形和菱形边框组合，不能把所有封闭区域当成同一种深度。
- GC16963、GC17092、GC17372 等 IGS 可见沿弯曲主体分布的字标；需判断承载面及投影/包覆方法，不能把平面拉伸强行当作曲面包字。
- GC15537 的 0.2 mm 是滴胶高度，不能当作凹字深度；GC17372 的抹油、GC17418 的凹位亮面属于表面工艺。当前工具不生成填油、细沙底或电镀工艺。

没有核定字深时保留为未知。统一工具不自动填入 0.2 mm；必须明确填写深度或高度。

## 1. 提取可复用轮廓

工具：`tools/logo-extract.py`，依赖 `ezdxf`、`shapely`（需要支持 Polygon.normalize）。输入为可靠转换并能完整解析的 DXF。读取 DWG/DXF 的原始 SHA256、源实体编号、图框、局部窗口和单位比例作为来源记录；不修改源图。

先核对标题栏/部件/修订，把 INSERT 展开后的产品视图和 LOGO 放大检查。选择包含该货号标题的图框 `--frame`，再选择只包含目标字形的窗口 `--bounds`，坐标顺序都是 xmin ymin xmax ymax。`--mm-per-unit` 必须显式给出；按尺寸标注确认，不能只靠屏幕观感。可用 `--layer` 限定轮廓层。

示例（本批 GC15763 的已核对窗口；路径请替换为自己的转换文件和输出目录）：

```text
python tools/logo-extract.py agent/temp/logo-dwg/GC15763/gc15763.dxf --product GC15763 --frame -561 590 -368 875 --bounds -442.8 722.8 -440.2 735.1 --mm-per-unit 1 --tolerance-mm 0.005 --source-dwg G:/TEXT-TO-CAD/drawings/DWG/GC/gc15763.dwg --output <输出目录>/GC15763.logo.json
```

本工作区的 AI 在 Windows 执行 CAD Python 时，通过 text-to-cad 的 `agent/tools/cad-learning/run-silent.ps1` 启动工作区内包装脚本，避免弹出窗口；此次包装脚本在 `F:/Project/text-to-cad/agent/temp/cad-learning/`。

输出 `.logo.json` 和轮廓预览 `.logo.svg`。JSON 内为 mm 坐标，原点归一到字形包围盒中心，区域结构是 `regions:[{outer:[[x,y],...],holes:[[[x,y],...],...]}]`，最后一条边隐式闭合。浏览器可导入安全子集 SVG，但不执行其中脚本或外部资源。

曲线按显式公差离散成直线段（默认 0.005 mm），因此生成的是有公差的折线轮廓，不是原始样条的无损恢复。只允许最大 0.0000001 mm 的端点数值噪声归并，记录实际移动量；不自动补设计断口、不缓冲修形。开线、相交/接触环、混货号图框和超限轮廓拒绝。跨窗口实体不提取并记录在 `excludedCrossingEntities`；必须查看预览确认整套字形完整，不能把“提取成功”当作选框正确的证明。TEXT/MTEXT 不替换为近似字体。

## 2. 浏览器加工

1. 打开或创建一个可编辑实心体，切换“面”，点击承载 LOGO 的一个目标面及放置点。
2. “加工 → 面与边 → LOGO”，导入已复核 `.logo.json` 或受限 SVG，核对名称、轮廓尺寸和内部孔洞。
3. 选择凹字/凸字，输入核定的深度或高度；设置缩放、旋转、镜像及面内偏移。
4. 预览后应用；右侧参数和历史步骤可继续修改。保存 `.webcad` 保留轮廓及来源，导出 STEP 供后续 CAD 使用。

新统一工具的放置原点是选中的三维点；旧 `logo` 步骤仍用选中面的面积中心。局部 X 为全局 X 向面上的投影；当 `abs(normal.x)>=0.9` 时改用全局 Y 投影。局部 Y 为面法向叉乘局部 X。依次镜像 X、统一缩放、旋转，再沿局部轴偏移。正/背面分别选面处理，朝向以三维预览为准。

每个区域必须实际增减材料；越出选定面的外边界或跨过该面的孔洞会失败，凸字必须连接主体。整个操作失败不提交半成品。曲面仍限原有单面等深凹刻，不支持凸字、拔模、跨面包覆、开放单线刻字或自动修补坏图。

## 3. 页面 AI 接口

使用 `window.webcad.api` 的 `getState()`、`queryGeometry()` 和 `execute()` / `run()`，工具卡 `getTool({id:"logo"})`，流程文档 `readDocs({docId:"api.logo"})`。新建传 `op:"logo"`、`refs:[当前实体ID]`，参数包括 `placementVersion:2`、当前 `faceId`、明确的 `point:[x,y,z]`、`regions`、`mode`、`depth`、`draftAngle` 等。内核按真实面类型分派；SVG 字符串本身不是 `regions`。旧 `curvedLogo` 只为历史工程兼容。

每次使用当前 `sessionId`、工程身份和 `expectedRevision`，不要跨修订复用旧拓扑序号。页面 API 的 JSON 面板可供仅能操作 UI 的侧栏 AI 使用；不需要 CLI 或第二份后台模型状态。历史编辑和重建保留旧工程几何语义。

## LOGO 脱模斜度

统一 LOGO 新建表单的拔模初值为 0°，可输入 0 至小于 45 度；depth 是必须确认的正数，单位 mm。0° 为直壁。平面承载面是中性面：其上的轮廓尺寸保持不变；凹字向底部收窄，凸字向顶部收窄，内孔反向倾斜。实际几何通过 OCCT 拔模生成，不是渲染效果。细窄笔画或深度/斜度过大导致失败时需减小参数，不自动降为 0°。曲面仅接受 0° 和凹刻。

旧工程未记录 draftAngle 时按原来的 0° 重建，属性栏显示 0，避免已有模型尺寸变化。旧 `curvedLogo` 步骤仍按原曲面算法重建；新统一步骤标记 `placementVersion:2`，目标面改变时拒绝代选。历史参数可编辑。


## PDF 转换与定位

「全局设置」可配置转换 URL（含 userid）与 Key，保存到当前浏览器同源 localStorage；页面 API 可读回两者。配置不进入工程文件，也不会随浏览器或站点域名自动迁移。PDF（≤20 MiB）由浏览器用 X-Key 直连已配置的转换服务，返回的 SVG 仍须校验并由用户确认。转换服务必须允许 WebCAD 页面来源的跨域 POST 和 X-Key 预检请求；保存配置成功不代表服务已允许浏览器直连。

LOGO 表单可选择九点锚位，以局部 X/Y 偏移对齐选中面上的三维放置点。箭头按指定毫米步长微调；应用后偏移留在历史特征中，选择该步骤可继续修改并重建。导入预览用填充及边框显示字形轮廓，颜色为预览色。
