# 选择、组合与拆散

多对象组合作为整体变换时，来源基点使用所选整体的明确原点或包围盒中心，成员间相对位置保持。拆散后分别读取当前 body ID；旧组的对象锚点若不能证明映射到新拓扑会标记为过期，不能静默指向任意子体。`group`/`extractSolid`/`extractFaces` 属于已有拓扑操作，工作基准不重定位其结果。

“编辑”位于菜单最前，启动时默认打开。箭头“选择”退出草图、测量、移动/旋转手柄及建模预览，回到实体选择。启动画面只保留文字提示，不放长方体等创建按钮。

- 组合：Ctrl / Shift 多选至少两个对象后点击组合，成为一个复合模型。它不执行布尔合并，不移动零件，也不会把接触或重叠的实体融合。
- 拆散：选择包含多个实体的模型后点击拆散，各实体成为独立设计树条目，原复合条目被替代。一次撤销可恢复原模型；拆散后可以单独移动、打孔等。
- 单个实体：如果 STEP 源文件已经把零件布尔融合为一个实体，不能从几何中恢复原有装配。需要用分割或切除建立新的分界。
- 当前拆散按真实 solid 分解，不是视觉爆炸位移，也不恢复原 CAD 特征树或装配约束。仅有曲面、没有 solid 的 IGS 模型不适用；需要曲面修补/缝合工作流。

MCP 支持 group（两个或以上 refs），拆散可通过 extractSolid 指定 solidIndex。界面批量拆散将所有提取作为一次历史事务，最多 500 个实体。
