# WebCAD agent rules

This is the independent WebCAD project copied from F:/Project/CadViewer. Never edit the original CadViewer as part of this task.
Keep notes under agent/notes, temporary scripts under agent/temp, deliverable reports under agent/output, and backups under agent/backups/<timestamp> preserving relative paths. Back up existing files before editing. Do not put scratch files in the root. No deployment to production or external uploads. Preserve third party licenses and the copied cad-viewer assets. Main product source lives in src/. Main owns main.js and viewport.js; delegated workers own only their assigned files. Read agent/notes/architecture.md before implementation.
