## 原针尖的实际进展与失败路线

原始文档哈希 `17c50b5ea195be8091fc827ac3a8a004d64499e545fa78adc503f8f6ff175a06`；基线 59 个面，GK 体积 119.08794576940558 mm³。基线种子边 80 对应内核轮廓 [77,80,132,111,110]。这些边号只对这一快照有效，续接必须重新查询。

| 路线 | 实际结果 / 拒收原因 |
| --- | --- |
| 原件原生重算 | R0.2 仍构造失败；另行明确试 R0.05、0.1、0.15、0.3，均 KERNEL_BUILD_FAILED。 |
| 独立 OCP 7.9.3.1 重算 | 从来源边签名解析同一轮廓，误差不超过 9e-15 mm；三种模式 × 默认/紧精度共六次，均 IsDone=false、一个失败轮廓。 |
| 清洁解析支撑面重算及刀具转移 | 单对支撑面原生圆角有效，转移到原件后接缝约 13.8/179 度；多支撑面并/顺序切割出现 TopOpeBRepDS_DataStructure::Point 异常。 |
| 裁出的前端支撑壳内偏置 | -0.2 mm 虽 IsDone=true，实际 Shape 为 null。 |
| C2 重画，拟合容差 1e-5 mm | 圆角结果无效；限定容差的 ShapeFixSolid、SameParameter 均不能修复。 |
| 偏置中心及圆弧加工刀具 | 81 个球心约束最大残差 8.4747877e-9 mm，但带延伸的圆弧放样刀具无效。21 个内部截面的刀具和切割结果有效，却留下 70 条尖缝、最大约 113.217 度，圆截面核验不通过。兼容性重排没有解决。 |
| 扫掠圆珠与楔形工具差集 | 单独工具有效，差集/材料转移卡住；任务自有卡住进程已经停止。OBB 变体完成后工具无效。 |
