## 二、目前已经完成的成果

### 1. 统一操作入口

- 新接口为 `rounding` v2：`{specVersion:2,sizeMm,scope:{kind:"edges",edgeIds}}`。
- 界面入口为“圆角”，用户只填写大小和选边；确认需要已有就绪预览。
- 解析选中边及内核实际轮廓，报告扩展选边、来源签名、处理范围和失败候选。
- 保留旧 `fillet` / `specVersion:1` 历史兼容；新工具发现目录隐藏旧 fillet。

### 2. 修复合法曲面的误拒绝

此前部分内核生成的真实圆角属于样条面，因为没有对应半径核验而被拒绝。现在直接测量 BREP 面的圆截面：尝试两个参数方向，每个方向五个站位，每截面十七点；半径误差、拟合残差、共面误差均要求不超过 `1e-5 mm`。

原生求解器采用更紧精度，接收结果依赖实际测量。对于扩展轮廓和没有分叉的闭合轮廓，采样检查生成面与支撑面的实际法线，接缝切向角要求不超过 `0.1°`。

### 3. 修复预览确认和工具目录问题

- 活动预览现在允许明确的 `preview.update`、`preview.commit`、`preview.cancel` 批处理。
- 单独 `preview.start` 的批处理可完成，其内部结果仍是 `previewing`；不会把预览描述成几何已经提交。
- 忙碌、计算中、工程身份和版本冲突仍有检查。
- 隐藏旧工具后，发现数量与实际可搜索数量统一为 197。
- 新增测试已进入正式分类，148 个测试文件没有漏分或重复。

### 4. 保留真实验证状态

候选逐个检查实体和材料变化；体积采用自适应 `BRepGProp.VolumePropertiesGK` 积分。失败方案保留实际回执；尚未独立验证的端部、接缝或其他要求保留未验证状态。

## 四、目前无法解决的问题

| 问题 | 已确认的事实 | 当前缺口 |
| --- | --- | --- |
| 原始针尖构造失败 | 原件有效，59 个面，GK 体积约 119.0879457694 mm³；原生 R0.2 构造失败 | 没有可接入工具的合格局部过渡 |
| 重画后接触不够平顺 | 部分重画代理可产生实测 R0.2，但端部仍约 1.30/1.23°；裁回原件后的候选最大约 5.29° | 接触面和端部约束仍不满足验收 |
| 刀具转移不稳定 | 部分刀具无效、布尔卡住，或出现两个/三个实体和加料 | 缺少稳定且材料方向正确的局部切割方法 |
| 端部和局部外形核验未完整 | 基础闭合案例通过；全部开口端部 G1 和局部外形不变尚未完整验证 | 不能声称任意选边都合格 |
| 历史拓扑解析未完成 | 报告记录来源边签名；边号仍是快照局部编号 | 缺少跨拓扑变化的稳定边解析器 |
| 真实产品验收未完成 | 原针尖未通过，其余五款不同产品仍未完成串行验收 | 18 处、72 张证据和后续加工验证尚缺 |

已证实同一来源几何、同一选边在独立 OCP 内核中仍失败。短边、分段支撑面和端部组合可能是困难因素，但本轮没有证明唯一根因，也不能由这些失败推导数学上无解。

## 五、已经尝试的方案及失败证据

| 尝试 | 结果和拒收原因 |
| --- | --- |
| 原件原生重算 | R0.2 失败；明确另试 R0.05、0.1、0.15、0.3，均 KERNEL_BUILD_FAILED |
| 独立 OCP 7.9.3.1 | 三种圆角模式 × 默认/紧精度共六次，均未完成构造；来源边签名匹配误差不超过 9e-15 mm |
| 清洁解析支撑面重算 | 单对支撑面圆角可有效，但转移到原件接缝约 13.8/179°；组合转移出现内核异常 |
| 前端支撑壳内偏置 | -0.2 mm 虽 IsDone=true，实际 Shape 为 null |
| C2 重画，拟合容差 1e-5 mm | 圆角结果无效，ShapeFixSolid 和 SameParameter 不能修复 |
| 偏置中心与圆弧加工刀具 | 球心约束残差小于 9e-9 mm，但延伸放样刀具无效；内部放样切割留下 70 条尖缝，最大约 113.217° |
| 扫掠圆珠与楔形工具 | 单独形状可有效，差集或转移卡住；OBB 变体完成后刀具无效 |

### 查看已构建页面

已安装 Node.js 的机器上，在解压后的 `WebCAD` 目录运行：

```powershell
$env:WEBCAD_STATIC_ROOT = 'dist'
$env:WEBCAD_STATIC_PORT = '17670'
node scripts/serve-static.mjs
```

然后使用现有浏览器标签页访问 `http://127.0.0.1:17670/`，可打开包内的曲面 R0.3 验证工程。当前这次整理没有启动新服务或新开浏览器。

### 重新安装依赖和构建

```powershell
npm ci
npm run build
```

本轮记录的环境为 Node.js v24.15.0、npm 11.12.1、replicad / replicad-opencascadejs 1.1.0。独立 OCP 探针使用 OCP 7.9.3.1；探针中的 `F:/Project/WebCAD` 为原机器路径，迁移后需要调整到解压目录。Windows Python 复现沿用包内静默启动工具和项目 `.venv`。
