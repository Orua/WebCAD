# 单面蘑菇撞钉

参数化两件式撞钉：解析球冠与背缘圆角、空心套筒、带相切浅腰的钉脚、圆肩与底盘。两件由LINE/ARC母线旋转生成；`explodedOffsetMm=0` 为静态同轴插入，大于0沿X分开展示。未模拟基材及铆压塑性变形。

`capDiameterMm`为实际最大直径，球半径由拱高、背缘圆角及最大直径解析推导。PG14412源R5和背缘R0.5相切得到实际直径9.94427191，与名义10存在0.05572809差异，产品实例保留源圆弧。默认直径10对应另一合法解析球半径，不声称原R5。

钉脚外径、尖端R、腰圆半径/深度/位置/相切圆角、肩圆角高度和底盘均可调。`postBoreDepthMm`为显式孔深，0不生成孔；`boreFromFlange`决定开孔方向。默认从底盘侧深5为形体可行示意，未获DWG孔深确认。Ø2.5大于源最小腰径约2.277，旧默认贯穿会切断，不能继承。改变孔深须保持钉脚单实体，不自动缩小腰或改孔以凑有效性。

不包含文字、LOGO、花纹、螺纹或单一货号的装饰细节。
