# 扁线双层匙圈

用两层平面圆弧和一个局部跨层放样生成连续单实体匙圈，截面为圆角矩形扁带。

- `innerDiameterMm`、`outerDiameterMm`：正视内外径，径向料宽为两者差的一半。
- `totalDepthMm`：侧视整件总厚。
- `turns`：连续绕卷圈数；常规双层匙圈通常接近两圈。
- `layerGapMm`：相邻叠层之间的小间隙。
- `leftHanded`：改变绕向。
- `sectionCornerRadiusMm`：截面圆角，不能把扁线当椭圆线。
- `transitionAngleDeg`：局部跨层所占角度，须能容纳于两圈未覆盖的开口扇区。

单层厚=(总厚−层间隙)/2；平层保持恒定高度，跨层连接采用有序截面三次放样。圈数须在1与2之间。工具不包括产品专属正视端帽；不同R端帽可使用解析arcProfile/cut组合，需要足够毛坯余量及限制切刀作用区，最后确认仍为完整单实体。局部三维盲倒圆即使solid数正确也可能BRep无效，不可放行。

2026-09-27：PG8566 与 PG12764 的图纸和实物图均确认内外圆扁带、侧向约 3 mm、开口叠层结构；其中 PG8566 标注内径 25、外径 33，PG12764 标注内径 25、外径 32。
