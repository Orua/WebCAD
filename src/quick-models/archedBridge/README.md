# 圆线拱桥（可选双底孔）

生成圆截面 U 形拱桥，两条直腿与精确半圆顶部连续成型，两端可开同轴底孔。

- `outerWidthMm`、`outerHeightMm`：成品外包络宽和高。
- `sectionDiameterMm`：圆截面桥身直径。
- `holeDiameterMm`、`holeDepthMm`：两端底孔直径与深度；两者同时为 0 时保留实心端部。

工具面向多款共用的常规圆线拱桥，不生成螺纹牙型、装配底片、装饰或异形截面。

2026-09-27：PG14749 图纸与实物图确认外宽 11.3、内宽 4.7、外高 7.5、内高 4.2、桥身直径 3.3、两端 2-M2；默认以直径 2、深 3 的光孔表达基本形状。
