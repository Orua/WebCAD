# 方线拱桥

固定快捷工具 `squareArchedBridge`，由 UI 和公共 `quickModel` API 共用，始终本地 WASM 执行。

结构来源：PG15272（ProductID 32622，2026-08-01）与 PG15227（ProductID 32506，2026-06-24）的正式 DWG 和实物图。默认主体外宽35.5、外高11.5、内宽25.5、内高8、厚5 mm；正面外转角R2、内转角R1.5来自PG15272图元。棱边R1、双M2.5孔位中心距30.5、孔深5来自图纸；本工具以直径2.5光孔表达安装位置，不宣称攻牙底径或实际螺纹。

PG15227参考参数：外宽23、外高11、内宽15、内高7、厚6、外R3、内R1、棱边R0（未标注，默认不猜）、底孔直径2.6、深5 mm。孔中心距由两腿中心确定，为19 mm。

这是共用平顶方线桥身工具，未复刻PG15272侧视微拱顶面，不包含底片、螺丝、标记、装配或制造公差。底端在Y=0，正面XY，厚度Z居中。内外转角独立，允许顶梁与腿宽不同；孔径及孔深同时设0关闭底孔。参数不合法或几何失败会明确报错，不静默缩减圆角或孔深。

API: `quickModel` 参数 `{kind:'squareArchedBridge', ...上述definition.js字段}`；返回正常特征/实体回执，通过 `getState`、`measure` 读回，参数编辑、撤销和工程保存走通用特征协议。
