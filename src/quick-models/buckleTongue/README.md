# 环头扁针

独立扣针基本形状，通过模型目录进入界面和 `quickModel` API。

- `lengthMm`：轴心至针尖距离；针沿 +Y。
- `widthMm`、`thicknessMm`：扁针宽度、厚度。
- `pivotDiameterMm`：配合轴直径；轴线沿 X。
- `clearanceMm`：轴孔直径增加量。

环头外半径 = (轴径 + 间隙) / 2 + 针厚。扣针不与扣身融合；抬起姿态用轴心周围的旋转实现。圆头半径使用针宽的 0.49 倍，避免圆角矩形在半宽处退化。
