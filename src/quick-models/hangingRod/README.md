# 圆杆吊环（吊杆）

生成一根水平圆杆，并在上方居中融合一个深度由根部向顶部收窄的椭圆截面U形吊环。

- `barLengthMm`、`barDiameterMm`：圆杆总长和直径。
- `endFilletMm`：两端圆周边的圆角半径。
- `loopInnerWidthMm`：吊环正视内宽。
- `loopWireDiameterMm`：吊环正视料宽及顶部Z深度。
- `loopRootDepthMm`：吊环根部Z深度，不能把它套到整个圈体。
- `rootBlendRadiusMm`：两脚与杆体交接处的局部圆角。
- `loopClearHeightMm`：从圆杆顶面到吊环内圈最高点的净高。

吊环使用21个有序截面三次放样，中心路径为直腿加半圆；Z深度从杆顶高度向中心路径顶点按高度收窄。向圆杆内部延伸半个料宽形成交叠，融合后按空间位置查询交接边做根圆角。截面接缝方向保持连续，不使用固定拓扑号。自由形面属于二维重建近似，需实际材料点验收。工具面向单吊环常规吊杆，不包含文字、花纹、多个吊环或异形杆体。

2026-09-27：GC12114 图纸与实物图确认圆杆总长 35、直径 5、端部 R0.8；吊环内宽 7、外宽 11、线径 2，整体高度 13。
