# 沿路径的线材或型材

技能path-section · 0.2.0 · 长度mm、角度degrees。示例尺寸只用于测试。

目的：用截面和中心路径表达弯线、框环和连续型材。

所需输入：源尺寸/坐标、目标部件、单位、用户指定的结构与要保持的部分；缺失会改变结果时先问清，不能借模板默认。前置状态：当前页面可执行、目标body及revision已知；改形后重查面边，选择集不能代替refs。

方案选择：先识别截面是圆/方/扁带，路径是中心线还是外轮廓；保存两者，确认路径起点切向与截面法向后profileSweep。

容易走错：圆截面转弯外轮廓不能直接当中心路径；方线D扣不能用圆线torus或通用D模板代替。

如何验收：检查截面、路径尺寸、闭合连接和弯曲自交；失败先查源平面和路径断点，不盲目加密。

失败后：先查第一个失败步骤、raw error和已提交内容，再按[诊断表](../problems/diagnosis.md)查证。只修正有证据的原因，不静默换尺寸/孔数/材料。批次非事务，原结果unknown先对账。

工具分支来自catalog.json。先定分支，再通过scripts/load.mjs --route path-section --branch 分支ID --tools读取当前完整卡。卡片是参数依据，正文负责判断何时用。正常与边界推理例见[例题](../examples/reasoned-cases.md)，实际执行状态见tests/results.json。
